🖨️ Bluetooth Printer Setup
📄
Paper width: 58mm · pre-set
How to connect your printer
1
Power on the thermal printer
Make sure paper is loaded and the power light is on.
2
Pair via Android Bluetooth settings
Go to Settings → Connected Devices → Bluetooth. Find your printer (common names: BT Printer, MTP-II, Goojprt, RPP02, HPRT) and tap Pair. If already paired, skip this step.
3
Install a Bluetooth print service
Pairing alone is not enough — Chrome needs a print service to see your printer.

Option A (recommended): Install Mopria Print Service from the Play Store — free, works with most printers.

Option B: Install PrintHand Mobile Print from the Play Store — better support for 58mm thermal printers via Bluetooth.

After installing, open the app once to activate it, then return here.
4
Select your printer
Tap Print Test Receipt below. Chrome will open a print dialog — tap the printer name at the top to change it. Your Bluetooth printer should now appear in the list.
5
Set paper size once
In the print dialog tap More settings → Paper size → choose 58mm or Custom (58mm width). Chrome remembers this setting going forward.
💡 Printer not showing up? After installing the print service, go to Android Settings → Connected Devices → Connection preferences → Printing, and make sure the service is enabled.
✅ Once set up, just power on the printer and tap Print — no repeat pairing needed.
